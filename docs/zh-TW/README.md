# Wizard 文件

[简体中文](../zh-CN/README.md) · **繁體中文** · [English](../en/README.md) · [日本語](../ja/README.md)

目前候選：**0.2.0 / build 20261112.41**。原始碼及[預覽安裝套件與素材](https://github.com/rexchen1803/wizard/releases/tag/v0.2.0-preview.5)均已公開。

簡體中文、繁體中文、English 與日本語文件涵蓋專案介紹與使用指南。時鐘編輯面板可選「海報」或「系統」字型，預設為使用 Anton-Regular 的「海報」。操作：長按時間 → 時間字體 → 海報／系統；完成儲存，取消復原。App 的日期、行事曆與天氣支援這四種語言；其他介面尚未全面在地化。截圖保留實際建置中的文字。原始碼、建置、模擬器呈現、安裝和實體裝置執行分別記錄證據。
