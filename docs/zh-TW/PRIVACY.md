# 本機資料與網路行為

[简体中文](../zh-CN/PRIVACY.md) · **繁體中文** · [English](../open-source/PRIVACY.md) · [日本語](../ja/PRIVACY.md)

本文說明目前 iPad 原始碼的行為，不是 App Store 隱私權揭露，也不代表裝置安全或執行驗收。

## 照片與偏好設定

Wizard 可通過系統照片選擇器匯入一張照片，將縮放後的 JPEG 和縮圖寫入 `/var/mobile/Media/iPadWizard/app/assets/user`。收藏、桌布裁切、時鐘與行事曆版面及字型設定保存在裝置上。刪除匯入桌布只會刪除 Wizard 的副本，不會刪除系統照片圖庫中的原圖。內建素材與使用者匯入素材分別管理。

經過審查的原始碼匯出不含個人照片、媒體庫、偏好設定、裝置快照、SSH 金鑰或連線憑證。匯出包含獲授權的 Anton 顯示字型、Wizard 自製啟動畫面和註明權利歸屬的 Vice City 預設桌布；歷史主題字型、音樂、完整影片與素材包不隨原始碼匯出。未安裝外部桌布資料夾時，也能單獨使用時鐘並匯入自己的照片。

## 投送與遠端播放

目前實現隨 App 啟動 DLNA/UPnP 接收器，在 HTTP `8199` 和 SSDP UDP `1900` 連接埠監聽，並在區域網路傳送探索通告。接收器會廣播裝置名稱和基於 vendor 識別碼生成的裝置識別碼。這些介面沒有傳送端身分驗證，適用於可信區域網路，不應通過路由器連接埠轉發暴露到外部網路。

傳送端可提交遠端媒體 URL。iPad 會直接連接該媒體伺服器，伺服器可獲得一般連線資訊，以及傳送端 URL 中的憑證或 token。為相容舊裝置與本機 HTTP 媒體，目前啟用了 `NSAllowsArbitraryLoads`；這不保證所有媒體來源都可播放。

SOAP 介面尚不完整：媒體 URL 提交會進入播放器，但 `Play`、`Pause`、`Stop` 和 `Seek` 動作沒有接入播放控制項。`GetTransportInfo` 固定回傳 `PLAYING`，`GetPositionInfo` 的時長與位置為零，音量和靜音查詢也回傳固定值。HTTP 成功或狀態回應不能作為實際播放狀態。

## 天氣

天氣為可選功能。啟用後，Wizard 請求定位權限，將經緯度傳送至 Open-Meteo HTTPS 預報介面，並使用 Apple 定位服務反向地理編碼城市名稱。裝置快取包含座標、城市、天氣和取得時間，以便顯示快取結果，或在無法定位時使用快取座標重試。關閉天氣會停止定位更新和定時重新整理。分發或啟用前，應核對服務商條款與署名要求；目前即時服務接入尚未驗收。

## 診斷與可選整合

診斷狀態可寫入 `/tmp` 等臨時路徑，可能包含桌布、播放 URL 和介面狀態。觸控與投送日誌需要臨時 `wizardsystem-debug` 標記；投送日誌可能包含私有播放 URL。效能與程式內影片控制項診斷需要各自的效能標記，天氣診斷使用獨立標記。分享前應審查並刪除個人資訊；原始碼匯出會排除歷史日誌和裝置狀態。

舊有 `wizardsystem` URL scheme 接受 App 控制、設定修改和電源整合命令，其中部分命令不要求診斷標記。它們與區域網路投送介面相互獨立。

原始碼中仍保留首頁/狀態檔案介面及實驗控制；存在原始碼不代表外部整合已配置。單獨提供的 WizardPower tweak 使用高權限 SpringBoard 行為和獨立偏好設定，屬於可選元件；建置或匯出 App 不會安裝它。

## 驗證範圍

程式碼檢查、主機迴歸和乾淨原始碼掃描不替代三台裝置上的資料流審查。遠端伺服器行為、裝置現有配置及第三方附加元件需要單獨驗證。網路、儲存、遙測或診斷行為變化後，應同步更新本文。
