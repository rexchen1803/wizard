# 本機資料與網路行為

[简体中文](../zh-CN/PRIVACY.md) · **繁體中文** · [English](../open-source/PRIVACY.md) · [日本語](../ja/PRIVACY.md)

本文說明目前 iPad 原始碼的行為，不是 App Store 隱私權揭露，也不代表裝置安全或執行驗收。

## 照片與偏好設定

Wizard 可通過系統照片選擇器匯入一張照片，將縮放後的 JPEG 和縮圖寫入 `/var/mobile/Media/iPadWizard/app/assets/user`。收藏、桌布裁切、時鐘與行事曆版面及字型設定保存在裝置上。刪除匯入桌布只會刪除 Wizard 的副本，不會刪除系統照片圖庫中的原圖。內建素材與使用者匯入素材分別管理。

經過審查的原始碼匯出不含個人照片、媒體庫、偏好設定、裝置快照、SSH 金鑰或連線憑證。匯出包含獲授權的 Anton 顯示字型、Wizard 自製啟動畫面和註明權利歸屬的 Vice City 預設桌布；歷史主題字型、音樂、完整影片與素材包不隨原始碼匯出。未安裝外部桌布資料夾時，也能單獨使用時鐘並匯入自己的照片。

## 投送與遠端播放

App 啟動時預設關閉投屏。按下投屏控制項並確認後才開啟區域網路接收；再次按下或進入背景會關閉。啟用期間使用 HTTP8199 與 SSDP UDP1900，透過隨機工作階段識別碼發現裝置，不再廣播廠商裝置識別碼。DLNA 沒有傳送端身分驗證，應在可信區域網路中使用，不要轉送連接埠。

每個 HTTP(S) 播放位址都須在 iPad 上確認後才會連線；提示只顯示主機名稱，關閉請求也會關閉接收服務。含使用者名稱/密碼、超過4096字元的位址，以及未啟用、未就緒或非前景狀態的請求會被拒絕。確認後 iPad 直接連線到所選媒體伺服器，對方會收到一般連線資訊與位址中的查詢權杖。`NSAllowsArbitraryLoads` 保留 HTTP 本機媒體支援。

SOAP 仍是部分實作：Play/Pause/Stop/Seek 未控制播放器，傳輸與播放位置回應為固定佔位值；HTTP 成功不代表實際播放。媒體目錄載入時拒絕路徑越界與子路徑符號連結，同時保留原有路徑身分；此檢查不防禦特權程序並行取代檔案。

## 天氣

天氣為可選功能。啟用後，Wizard 請求定位權限，將經緯度傳送至 Open-Meteo HTTPS 預報介面，並使用 Apple 定位服務反向地理編碼城市名稱。裝置快取包含座標、城市、天氣和取得時間，以便顯示快取結果，或在無法定位時使用快取座標重試。關閉天氣會停止定位更新和定時重新整理。分發或啟用前，應核對服務商條款與署名要求；目前即時服務接入尚未驗收。

## 診斷與可選整合

實體裝置的診斷狀態須有臨時 `wizardsystem-debug` 標記才會寫出；獨立模擬器預覽可記錄測試狀態。狀態可能包含桌布與播放位址，分享前應去識別化。Cast 記錄同樣須主動啟用，只記錄主機與狀態，不記錄完整播放位址、查詢權杖或請求本文。天氣及效能診斷保留各自的主動啟用標記。原始碼匯出不含記錄、使用者媒體或裝置資料。

裝置版 `wizardsystem` URL 只接受供可選電源插件啟動 App 的精確路徑 `wizardsystem://main`；外部設定與電源控制命令均被拒絕。模擬器診斷另走受限 CLI 入口，不構成裝置 IPC 授權。

實驗性檔案介面與可選 WizardPower 插件保留文件中的 rootful 環境要求；安裝程式不會安裝該插件或啟用特權整合。


可選電源插件不再註冊遠端 Darwin 鎖屏、喚醒或狀態請求；本機電源線觸發的自動化保留。其診斷記錄須有臨時 `wizardpower-debug` 標記才會寫入。

## 驗證範圍

程式碼檢查、主機迴歸和乾淨原始碼掃描不替代三台裝置上的資料流審查。遠端伺服器行為、裝置現有配置及第三方附加元件需要單獨驗證。網路、儲存、遙測或診斷行為變化後，應同步更新本文。
