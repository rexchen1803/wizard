# 安全政策

[简体中文](../zh-CN/SECURITY.md) · **繁體中文** · [English](../../SECURITY.md) · [日本語](../ja/SECURITY.md)

Wizard 面向舊款 iPad，使用外部媒體路徑、區域網路媒體控制和 Apple 私有框架。使用前請閱讀[隱私與網路說明](PRIVACY.md)及[相容性範圍](COMPATIBILITY.md)。

## 通報弱點

儲存庫啟用 GitHub 私密弱點報告後，請透過[私密弱點入口](https://github.com/rexchen1803/wizard/security/advisories/new)報告。不要在公開 Issue 中發佈未修復弱點、憑證、私有日誌、裝置識別碼或個人媒體。請註明受影響的原始碼版本或 Wizard build、相關 iPad 型號和系統，以及簡短重現步驟；移除個人與網路相關資訊。

若私密報告入口尚不可用，請保留弱點細節，等待私密管道開放，不要改用公開 Issue 披露。專案暫不承諾回應時限或支援週期。

## 版本支援

目前沒有承諾裝置支援的正式版本。目前候選與驗證範圍見[相容性指南](COMPATIBILITY.md)。主機迴歸不能證明裝置安全性或執行支援。
