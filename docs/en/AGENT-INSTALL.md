# Agent Installation Prompt

[简体中文](../AGENT-INSTALL.md) · [繁體中文](../zh-TW/AGENT-INSTALL.md) · **English** · [日本語](../ja/AGENT-INSTALL.md)

Giving the complete prompt below to Codex or another agent authorizes one attempted Wizard preview installation on one already prepared, currently connected iPad that you have identified. The authorization is limited to build `20261112.40`, that device, and this installation. It covers read-only checks, obtaining and verifying the pinned package, one installation, at most one Wizard stop during an update, and retention of the complete rollback bundle created by the installer. It does not authorize jailbreaking, password changes, connection setup, installing the power tweak, launching the app, respringing, rebooting, or changing repository publication status.

The repository is private and all Releases are drafts. `v0.2.0-preview.4` has no public download endpoint. The fixed URLs below are marked **available only after publication**. The agent must first confirm that it can obtain the exact `.deb` and matching manifest through an already authorized repository access method. If the files are unavailable, it must stop and report before contacting the device. It must not publish a Release, change repository visibility, or switch to `latest` or another version.

## Prompt

```text
I authorize you to attempt one installation of Wizard 0.2.0 / build 20261112.40 on only the currently connected, already prepared iPad that I have explicitly identified. This authorization covers only the read-only checks, retrieval and verification of the fixed package, one installation, at most one Wizard stop by the installer during an update, and retention of the complete previous app bundle for rollback. Do not ask again for these authorized steps. If the target device is unclear, ask only which device it is. Stay within the device, version, and action limits below.

The repository is private and all GitHub Releases are drafts. v0.2.0-preview.4 is unpublished, so the GitHub download paths below are future pinned URLs and there is currently no public download endpoint. Before connecting to or operating the device, use only currently authorized repository access to confirm that the exact .deb and matching manifest are actually obtainable. If either file is unavailable, stop and report immediately. Do not contact or operate the device. Do not publish a Release, change repository visibility, create a download endpoint, use latest, switch to another version, or obtain a replacement package from another source. The Releases page is only an entry point for an already authorized maintainer account to inspect drafts: https://github.com/rexchen1803/wizard/releases

The only accepted build40 files and their fixed paths after publication are:
- wizard_0.2.0-20261112.40_iphoneos-arm.deb
  https://github.com/rexchen1803/wizard/releases/download/v0.2.0-preview.4/wizard_0.2.0-20261112.40_iphoneos-arm.deb
- wizard_0.2.0-20261112.40_iphoneos-arm.deb.manifest.json
  https://github.com/rexchen1803/wizard/releases/download/v0.2.0-preview.4/wizard_0.2.0-20261112.40_iphoneos-arm.deb.manifest.json

1. Before any device connection, confirm that both exact files are obtainable from the authorized source, that their names and package version match, and that the .deb SHA-256 equals artifact_sha256 in the manifest. If a file is missing, its hash or version differs, or its source is different, stop and report; do not proceed to device checks.
2. Only after step 1 passes, run read-only preflight checks on the single target device: read its exact model and iOS version; confirm a rootful jailbreak, Debian package environment, root access, writable non-symlink /Applications, and availability of sysctl, sw_vers, ldid, uicache, and killall; and check whether a Wizard bundle is installed. Use only an already configured and authorized local USB or SSH channel. Do not create accounts, change passwords, enable SSH, change networking, install certificates, or change trust settings. If that authorized channel is configured but lacks a login credential, ask only for that credential. Stop if the connection fails or requires any other unauthorized setup.
3. Accept only these exact model and OS pairs: iPad2,4 + iOS 9.3.5; iPad3,4 + iOS 10.3.3; iPad4,1 + iOS 12.5.8. Stop on stock iOS, rootless jailbreak, iPhone, or any other model or version. Do not try to create or repair a jailbreak or bypass preflight checks.
4. After preflight passes, install only this fixed .deb using the device's existing Cydia, Sileo, Zebra, Filza, or an already authorized rootful dpkg workflow. This one installation is authorized by this prompt. During an update, the installer may send Wizard one TERM command and must retain the existing WizardSystem.app intact as WizardSystem.rollback-<build>-<UTC>.app. It uses the device's existing ldid to sign the app and calls uicache to register it. Do not install the power tweak, launch Wizard, respring, reboot, or operate any other app. A fresh installation has no previous app rollback bundle.
5. After installation, read back only the bundle ID, version, build, app path, package-manager result, and whether the media directory and preferences still exist. Do not read, copy, or output media contents or preference values. Do not launch the app. State clearly: “Build 20261112.40 has not been accepted on a physical device.” Installer or package-manager success is not user acceptance.
6. If installation fails, a key state cannot be read, or the installer reports an error, record the original error and stop. Preserve every WizardSystem.app, WizardSystem.rollback-*, WizardSystem.uninstalled-*, and WizardSystem.failed-* directory. Do not delete, overwrite, manually repair, or guess at cleanup. Do not force a respring or reboot.

Do not uninstall the Debian package unless I make a separate explicit request to uninstall it. If removal is authorized, the package removal hook unregisters only a Wizard app whose build matches the package and retains the complete bundle as WizardSystem.uninstalled-<build>-<UTC>.app; media, preferences, and existing rollback bundles are preserved. To restore it, reinstall the same fixed .deb to restore the helper, then follow the rollback instructions in docs/INSTALL.md using the actual WizardSystem.uninstalled-* path. Do not let dpkg or a manual command remove a recovery bundle.

This authorization does not include downloading or installing Rockstar media. Process the gallery only if I separately and explicitly ask for a gallery installation. The gallery is also in the unpublished v0.2.0-preview.4 draft; if the attachment cannot be obtained through authorized access, stop. Do not publish a Release or change repository visibility. After publication, the only accepted gallery file is wizard-gta6-gallery-20261112.zip, with SHA-256 b8bd883b81a0a76086217ce3c27091d83b0b8261dcbabae49c88abb67aef3eba; its fixed future URL is:
https://github.com/rexchen1803/wizard/releases/download/v0.2.0-preview.4/wizard-gta6-gallery-20261112.zip
If I explicitly authorize gallery installation, first make a complete backup of /var/mobile/Media/iPadWizard/app, verify the hash, and merge the ZIP's app/ contents into that directory. Never replace the entire app/ directory; preserve assets/user, imported user photos, and preferences. The original-media archive is not the device gallery package. Rockstar attribution does not grant redistribution rights.
```

Source builds, prompt authorization, checksum verification, installer success, and physical-device acceptance are separate kinds of evidence. See the [compatibility guide](../COMPATIBILITY.md) for device evidence and the [installation guide](INSTALL.md) for full installation and recovery instructions.
