# 本地数据与网络行为

**简体中文** · [繁體中文](../zh-TW/PRIVACY.md) · [English](../open-source/PRIVACY.md) · [日本語](../ja/PRIVACY.md)

本文说明当前 iPad 源码的行为，不是 App Store 隐私申报，也不代表设备安全或运行验收。

## 照片与偏好

Wizard 可通过系统照片选择器导入一张照片，将缩放后的 JPEG 和缩略图写入 `/var/mobile/Media/iPadWizard/app/assets/user`。收藏、壁纸裁切、时钟与日历布局及设置保存在设备上。删除导入壁纸只会删除 Wizard 的副本，不会删除系统照片图库中的原图。内置素材与用户导入素材分别管理。

经过审查的源码导出不含个人照片、媒体库、偏好、设备快照、SSH 密钥或连接凭据。导出包含获许可的 Anton 显示字体、Wizard 自制启动图和注明权利归属的 Vice City 默认壁纸；历史主题字体、音乐、完整视频与素材包不随源码导出。未安装外部壁纸目录时，也可运行时钟并导入自己的照片。

## 投送与远程播放

当前实现随 App 启动 DLNA/UPnP 接收器，在 HTTP `8199` 和 SSDP UDP `1900` 端口监听，并在局域网发送发现通告。接收器会广播设备名称和基于 vendor 标识生成的设备标识。这些接口没有发送端身份验证，适用于可信局域网，不应通过路由器端口转发暴露到外部网络。

发送端可提交远程媒体 URL。iPad 会直接连接该媒体服务器，服务器可获得正常连接信息，以及发送端 URL 中的凭据或 token。为兼容旧设备与本地 HTTP 媒体，当前启用了 `NSAllowsArbitraryLoads`；这不保证所有媒体来源都可播放。

SOAP 接口尚不完整：媒体 URL 提交会进入播放器，但 `Play`、`Pause`、`Stop` 和 `Seek` 动作没有接入播放控件。`GetTransportInfo` 固定返回 `PLAYING`，`GetPositionInfo` 的时长与位置为零，音量和静音查询也返回固定值。HTTP 成功或状态回包不能作为真实播放状态。

## 天气

天气为可选功能。启用后，Wizard 请求定位权限，将经纬度发送到 Open-Meteo HTTPS 预报接口，并使用 Apple 定位服务反向地理编码城市名称。设备缓存包含坐标、城市、天气和获取时间，以便显示缓存结果，或在无法定位时使用缓存坐标重试。关闭天气会停止定位更新和定时刷新。分发或启用前，应核对服务商条款与署名要求；当前实时服务接入尚未验收。

## 诊断与可选集成

诊断状态可写入 `/tmp` 等临时路径，可能包含壁纸、播放 URL 和界面状态。触摸与投送日志需要临时 `wizardsystem-debug` 标记；投送日志可能包含私有播放 URL。性能与进程内视频控件诊断需要各自的性能标记，天气诊断使用独立标记。分享前应审查并删去个人信息；源码导出会排除历史日志和设备状态。

旧有 `wizardsystem` URL scheme 接受 App 控制、设置修改和电源集成命令，其中部分命令不要求诊断标记。它们与局域网投送接口相互独立。

源码中仍保留主页/状态文件接口及实验控制；存在源码不代表外部集成已配置。单独提供的 WizardPower tweak 使用高权限 SpringBoard 行为和独立偏好，属于可选组件；构建或导出 App 不会安装它。

## 验证范围

代码检查、宿主机回归和干净源码扫描不替代三台设备上的数据流审查。远程服务器行为、设备现有配置及第三方附加组件需要单独验证。网络、存储、遥测或诊断行为变化后，应同步更新本文。
