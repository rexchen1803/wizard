# 本地数据与网络行为

**简体中文** · [繁體中文](../zh-TW/PRIVACY.md) · [English](../open-source/PRIVACY.md) · [日本語](../ja/PRIVACY.md)

本文说明当前 iPad 源码的行为，不是 App Store 隐私申报，也不代表设备安全或运行验收。

## 照片与偏好

Wizard 可通过系统照片选择器导入一张照片，将缩放后的 JPEG 和缩略图写入 `/var/mobile/Media/iPadWizard/app/assets/user`。收藏、壁纸裁切、时钟与日历布局及设置保存在设备上。删除导入壁纸只会删除 Wizard 的副本，不会删除系统照片图库中的原图。内置素材与用户导入素材分别管理。

经过审查的源码导出不含个人照片、媒体库、偏好、设备快照、SSH 密钥或连接凭据。导出包含获许可的 Anton 显示字体、Wizard 自制启动图和注明权利归属的 Vice City 默认壁纸；历史主题字体、音乐、完整视频与素材包不随源码导出。未安装外部壁纸目录时，也可运行时钟并导入自己的照片。

## 投送与远程播放

App 启动时默认关闭投屏。点击投屏控件并确认后才开放局域网接收；再次点击或进入后台会关闭。启用期间使用 HTTP8199 和 SSDP UDP1900，通过随机会话标识发现设备，不再广播厂商设备标识。DLNA 没有发送端身份认证，应在可信局域网中使用，不要转发端口。

每个 HTTP(S) 播放地址都须在 iPad 上确认后才会请求；弹窗只显示主机名，关闭请求也会关闭接收服务。含用户名/密码、超过4096字符的地址，以及未启用、未就绪或非前台状态下的请求会被拒绝。确认后，iPad 直接连接所选媒体服务器，对方会收到正常连接信息及发送地址中的查询令牌。`NSAllowsArbitraryLoads` 保留对 HTTP 本地媒体的支持。

SOAP 仍为部分实现：Play/Pause/Stop/Seek 未控制播放器，传输和播放位置响应为固定占位值；HTTP 成功不代表实际播放。媒体目录在加载时拒绝路径越界与子路径符号链接，同时保留原有路径身份；此检查不防御特权进程并发替换文件。

## 天气

天气为可选功能。启用后，Wizard 请求定位权限，将经纬度发送到 Open-Meteo HTTPS 预报接口，并使用 Apple 定位服务反向地理编码城市名称。设备缓存包含坐标、城市、天气和获取时间，以便显示缓存结果，或在无法定位时使用缓存坐标重试。关闭天气会停止定位更新和定时刷新。分发或启用前，应核对服务商条款与署名要求；当前实时服务接入尚未验收。

## 诊断与可选集成

实体设备的诊断状态须有临时 `wizardsystem-debug` 标记才会写出；独立模拟器预览可记录测试状态。状态可能包含壁纸和播放地址，分享前应脱敏。Cast 日志同样须主动启用，只记录主机和状态，不记录完整播放地址、查询令牌或请求正文。天气及性能诊断保留各自的主动启用标记。源码导出不含日志、用户媒体或设备记录。

设备版 `wizardsystem` URL 仅接受供可选电源插件启动 App 的精确路径 `wizardsystem://main`；外部设置与电源控制命令均被拒绝。模拟器诊断另走受限 CLI 入口，不构成设备 IPC 授权。

实验性文件接口和可选 WizardPower 插件保留文档中的 rootful 环境要求；安装器不会安装该插件或启用特权集成。


可选电源插件不再注册远程 Darwin 锁屏、唤醒或状态请求；本机电源线触发的自动化保留。其诊断日志须有临时 `wizardpower-debug` 标记才会写入。

## 验证范围

代码检查、宿主机回归和干净源码扫描不替代三台设备上的数据流审查。远程服务器行为、设备现有配置及第三方附加组件需要单独验证。网络、存储、遥测或诊断行为变化后，应同步更新本文。
