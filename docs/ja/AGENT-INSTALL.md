# エージェント向けインストール用プロンプト

以下のプロンプト全文を Codex または別のエージェントに渡すと、利用者が特定した、準備済みで現在接続中の iPad 1台に対して Wizard プレビューのインストールを1回試みる権限を与えます。この権限は build `20261112.41`、その端末、そのインストール作業に限られます。読み取り専用の確認、固定パッケージの取得と検証、インストール1回、更新時に限る Wizard の停止1回まで、およびインストーラーが作成する完全な ロールバック用バンドルの保持を含みます。脱獄、パスワード変更、接続設定、電源 tweak のインストール、アプリ起動、respring、再起動、リポジトリ公開状態の変更は許可しません。

ソースリポジトリは公開されていますが、GitHub Releases はすべて下書き状態です。`v0.2.0-preview.5` はドラフトで、公開ダウンロード URL はありません。以下の固定 URL は公開後に限り有効です。エージェントは、既に許可された取得方法で正確な `.deb` と対応 manifest の両方を入手できることを先に確認します。取得できなければ端末に接続する前に停止して報告してください。リリースを公開したり、リポジトリの公開設定を変えたり、`latest` や別バージョンへ切り替えたりしてはいけません。

## プロンプト

```text
利用者が明示した、準備済みで現在接続中の iPad 1台だけに Wizard 0.2.0 / build 20261112.41 のインストールを1回試みることを許可します。この権限に含まれるのは、読み取り専用の確認、固定パッケージの取得と検証、インストール1回、更新時にインストーラーが行う Wizard の停止1回まで、および ロールバック用の既存アプリ一式の保持だけです。許可されたこれらの手順について再確認を求めないでください。対象端末が特定できない場合は、どの端末かだけを質問してください。以下の端末、バージョン、操作の範囲を守ってください。

ソースリポジトリは公開されていますが、GitHub Releases はすべて下書き状態です。v0.2.0-preview.5 は未公開です。以下の GitHub ダウンロードパスは公開後に使う固定 URL で、現在公開ダウンロード先はありません。端末に接続・操作する前に、許可済みのリポジトリアクセスだけを使い、正確な .deb と対応 manifest を実際に取得できることを確認してください。どちらかを入手できなければ、直ちに停止して報告してください。端末には接続も操作もしないでください。リリースを公開する、リポジトリの公開設定を変更する、ダウンロード先を作る、latest を使う、別バージョンへ切り替える、別の取得元から代替パッケージを得ることは禁止です。Releases ページは、許可されたメンテナーが下書きを確認する入口に限られます: https://github.com/rexchen1803/wizard/releases

受け入れる build 41 の固定ファイルと公開後の固定パス:
- wizard_0.2.0-20261112.41_iphoneos-arm.deb
  https://github.com/rexchen1803/wizard/releases/download/v0.2.0-preview.5/wizard_0.2.0-20261112.41_iphoneos-arm.deb
- wizard_0.2.0-20261112.41_iphoneos-arm.deb.manifest.json
  https://github.com/rexchen1803/wizard/releases/download/v0.2.0-preview.5/wizard_0.2.0-20261112.41_iphoneos-arm.deb.manifest.json

1. 端末へ接続する前に、正確な2ファイルが許可された取得元から入手できること、名前とパッケージバージョンが一致すること、.deb の SHA-256 が manifest の artifact_sha256 と一致することを確認する。ファイルがない、ハッシュやバージョンが違う、取得元が異なる場合は停止して報告する。端末確認に進まない。
2. 手順1の確認に通った後だけ、対象端末1台で読み取り専用の事前確認を行う。正確な機種と iOS バージョン、rootful 脱獄、Debian パッケージ環境、root 権限、シンボリックリンクではない書き込み可能な /Applications、sysctl、sw_vers、ldid、uicache、killall の有無、Wizard バンドルのインストール状況を調べる。既に設定済みで許可された USB または SSH 接続だけを使う。アカウント作成、パスワード変更、SSH 有効化、ネットワーク変更、証明書インストール、信頼設定変更は禁止。許可済み接続が設定済みでもログイン資格情報だけが不足する場合は、その資格情報だけを尋ねる。それ以外の準備が必要、または接続に失敗したら停止する。
3. 次の機種と OS の組み合わせだけを受け付ける: iPad2,4 + iOS 9.3.5、iPad3,4 + iOS 10.3.3、iPad4,1 + iOS 12.5.8。通常の iOS、rootless 脱獄、iPhone、他の機種またはバージョンでは停止する。脱獄の作成・修復や事前確認の回避を試みない。
4. 事前確認に通った後、端末に既存の Cydia、Sileo、Zebra、Filza、または既に許可された rootful dpkg の手順だけで、この固定 .deb のみをインストールする。このプロンプトはこのインストール1回を許可する。更新時、インストーラーは Wizard に TERM を1回送り、既存の WizardSystem.app 全体を WizardSystem.rollback-<build>-<UTC>.app として保持する。端末にある既存の ldid でアプリに署名し、uicache で登録する。電源 tweak のインストール、Wizard の起動、respring、再起動、他のアプリの操作は禁止。新規インストールには旧アプリの ロールバック用バンドルはない。
5. インストール後は bundle ID、バージョン、build、アプリのパス、パッケージマネージャーの結果、メディアディレクトリと設定ファイルが存在するかどうかだけを読み戻す。メディア内容や設定値を読んだり、コピーしたり、出力したりしない。アプリを起動しない。必ず次のとおり明記する: 「Build 20261112.41 は実機で受け入れられていません。」インストーラーやパッケージマネージャーの成功は利用者の受け入れではない。
6. インストール失敗、重要な状態を読み戻せない、インストーラーがエラーを報告した場合は、元のエラーを記録して停止する。WizardSystem.app、WizardSystem.rollback-*、WizardSystem.uninstalled-*、WizardSystem.failed-* のすべてを保持する。削除、上書き、手動修復、推測による後片付けはしない。respring や再起動を強制しない。

別途明示的に依頼されない限り、Debian パッケージをアンインストールしないこと。削除が許可された場合、削除フックはパッケージと build が一致する Wizard アプリだけを登録解除し、完全なバンドルを WizardSystem.uninstalled-<build>-<UTC>.app として保持する。メディア、設定、既存 ロールバック用バンドルは保持される。復元するには同じ固定 .deb を再インストールして補助ツールを戻し、docs/INSTALL.md のロールバック手順に実在する WizardSystem.uninstalled-* パスを指定する。dpkg や手動コマンドで復旧バンドルを削除させないこと。

この権限は Rockstar 素材の取得・インストールを含まない。ギャラリーは、利用者が別途明示的に依頼した場合だけ扱うこと。ギャラリーも未公開の v0.2.0-preview.5 の下書きに添付されています。許可されたアクセスで添付を取得できなければ停止する。リリースを公開したり、リポジトリの公開設定を変更したりしない。公開後に受け入れるギャラリーファイルは wizard-gta6-gallery-20261112.zip のみで、SHA-256 は b8bd883b81a0a76086217ce3c27091d83b0b8261dcbabae49c88abb67aef3eba、固定予定 URL は次のとおり:
https://github.com/rexchen1803/wizard/releases/download/v0.2.0-preview.5/wizard-gta6-gallery-20261112.zip
ギャラリー導入を明示的に許可された場合は、最初に /var/mobile/Media/iPadWizard/app 全体の完全なバックアップを作り、ハッシュを確認してから ZIP 内の app/ 内容をそのディレクトリにマージする。app/ 全体を置き換えない。assets/user、ユーザーが取り込んだ写真、設定を保持する。原素材アーカイブは端末用ギャラリーパッケージではない。Rockstar への帰属表示は再配布権を与えない。
```

ソースビルド、プロンプトによる許可、チェックサム確認、インストーラー成功、実機受け入れは別々の証拠です。端末の証拠は[互換性ガイド](COMPATIBILITY.md)、インストールと復旧手順は[インストールガイド](INSTALL.md)を参照してください。
