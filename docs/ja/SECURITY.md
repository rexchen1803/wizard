# セキュリティポリシー

Wizard は旧世代 iPad 向けのソースプロジェクトです。アプリは外部メディアの保存先、ローカルネットワークのメディア制御、Apple の非公開フレームワークを使います。利用前に[プライバシーの説明](PRIVACY.md)と[互換性の制限](COMPATIBILITY.md)を確認してください。

## 脆弱性を報告する

このリポジトリで利用できる場合は、[GitHub の非公開脆弱性報告](https://github.com/rexchen1803/wizard/security/advisories/new)を使ってください。未修正の脆弱性、認証情報、非公開ログ、端末識別子、個人メディアを公開の issue に投稿しないでください。該当するソース revision または Wizard の build、必要に応じて iPad の機種と iOS のバージョン、簡潔な再現手順を記載してください。個人情報とネットワーク情報はマスキングしてください。

非公開の報告手段が利用できない場合、issue に攻撃手順の詳細を載せず、非公開の報告経路が使えるまで待ってください。応答時間やサポートの約束はありません。

## 対応バージョン

現時点で対応対象として公開された実機リリースはありません。現行のソース候補は[互換性ガイド](COMPATIBILITY.md)に記載されています。ホスト回帰結果は、端末でのセキュリティや実行時サポートを証明しません。
