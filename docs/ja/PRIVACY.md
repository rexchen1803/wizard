# ローカルデータとネットワーク動作

この文書は iPad 向けソース候補の説明です。App Store のプライバシー申告でも、実機受け入れの証拠でもありません。

## 写真と設定

Wizard はシステムの写真選択画面で選んだ写真を取り込めます。サイズ変更した JPEG とサムネイルを `/var/mobile/Media/iPadWizard/app/assets/user` に書き込みます。お気に入り、壁紙のフレーミング、時計／カレンダーのレイアウト、設定は端末に保存します。利用者が取り込んだ壁紙を削除すると Wizard 内のコピーを削除します。Photos 内の原本は削除しません。同梱メディアと利用者が取り込んだメディアは別です。

確認済みのソース書き出しには、個人写真、メディアライブラリ、設定、端末の記録、SSH 鍵、接続資格情報は含まれません。ライセンス済み Anton ディスプレイフォント、Wizard 作成の起動画像、帰属表示付き Vice City 代替壁紙は含まれます。過去のテーマフォント、音楽、フル動画／メディアパックは除外されています。任意の外部壁紙カタログがなくても時計を使い、自分の写真を取り込めます。

## Cast とリモート再生

現行実装はアプリとともに DLNA/UPnP 受信機を起動します。HTTP のポート8199と、SSDP 検出用 UDP ポート1900で待ち受け、ローカルネットワークに検出通知を送ります。受信機は機器名とベンダー由来の識別子を通知します。これらの接続先は信頼できるローカルネットワーク向けで、送信元の認証機能はありません。ルーターでポート転送を設定して外部公開しないでください。

Cast の送信側はリモートメディアの URL を渡せます。再生時、iPad はメディアサーバーへ直接接続します。サーバーには通常の接続情報に加えて、送信側の URL に含まれる認証情報や token も送られます。古い端末とローカル HTTP メディアソースに対応するため、現在 `NSAllowsArbitraryLoads` を有効にしています。これは互換性に関する説明であり、すべてのメディアが再生できる保証ではありません。

公開される SOAP 機能は一部のみです。URL はプレーヤーに届きますが、`Play`、`Pause`、`Stop`、`Seek` の各操作は再生制御につながっていません。`GetTransportInfo` は固定の `PLAYING` を返し、`GetPositionInfo` は長さ／位置をゼロで返します。音量／ミュート query も固定値です。これらのインターフェースは将来の実装用に残っています。HTTP 成功や状態応答は、実際の再生状態を示しません。

## 天気

天気機能は任意です。有効にすると Wizard は位置情報の許可を求め、緯度／経度を Open-Meteo の HTTPS 天気予報サービスに送ります。逆ジオコーディングには Apple の位置情報サービスを使って都市名を取得します。端末内のキャッシュには座標、都市、天気、取得時刻を保存します。保存済みの天気を表示でき、位置情報が使えない場合は保存済みの座標で再試行します。天気を無効にすると位置情報更新と定期更新を止めます。配布前に評価対象プロバイダーの現行条件と帰属要件を確認してください。

## 診断と任意連携

診断情報は `/tmp` 以下に書き込まれる場合があり、壁紙、再生 URL、画面の状態を含むことがあります。Touch と Cast のログ出力には一時的な `wizardsystem-debug` 有効化マーカーが必要です。Cast ログには非公開の再生 URL が含まれることがあります。性能とアプリ内動画制御の診断には一時的な性能マーカーを、天気の診断には別の有効化マーカーを使います。診断には個人情報が含まれる可能性があります。共有前に内容を確認し、個人情報を伏せてください。公開用の書き出しでは過去のログと端末状態を除外します。

旧 `wizardsystem` カスタム URL スキームは、アプリ操作、設定変更、電源連携コマンドを受け付けます。一部の旧 command は診断 marker なしで利用できます。これらはローカルネットワークの Cast endpoint とは別です。

ホーム／状態ファイルのインターフェースと実験用の操作機能はソースに残っています。ソースにあることは、外部連携が設定済みである証明ではありません。同梱の WizardPower tweak は特権を持つ SpringBoard 動作と独自の端末設定を使い、任意コンポーネントです。アプリのビルドやソース書き出しではインストールされません。

## 検証の限界

コード確認、ホスト回帰検査、書き出し内容の確認は、3機種でのデータの流れの確認とは別です。リモートサーバーの動作、インストール済み端末の設定、第三者追加物は、それぞれ別途検証が必要です。ネットワーク、保存、利用状況データや診断動作が変わった場合は、この文書を見直してください。
