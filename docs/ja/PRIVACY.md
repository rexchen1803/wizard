# ローカルデータとネットワーク動作

この文書は iPad 向けソース候補の説明です。App Store のプライバシー申告でも、実機受け入れの証拠でもありません。

## 写真と設定

Wizard はシステムの写真選択画面で選んだ写真を取り込めます。サイズ変更した JPEG とサムネイルを `/var/mobile/Media/iPadWizard/app/assets/user` に書き込みます。お気に入り、壁紙のフレーミング、時計／カレンダーのレイアウト、設定は端末に保存します。利用者が取り込んだ壁紙を削除すると Wizard 内のコピーを削除します。Photos 内の原本は削除しません。同梱メディアと利用者が取り込んだメディアは別です。

確認済みのソース書き出しには、個人写真、メディアライブラリ、設定、端末の記録、SSH 鍵、接続資格情報は含まれません。ライセンス済み Anton ディスプレイフォント、Wizard 作成の起動画像、帰属表示付き Vice City 代替壁紙は含まれます。過去のテーマフォント、音楽、フル動画／メディアパックは除外されています。任意の外部壁紙カタログがなくても時計を使い、自分の写真を取り込めます。

## Cast とリモート再生

Cast は起動時に無効です。Cast 操作を確認するとローカルネットワークの受信を開始し、再度の操作、バックグラウンド移行で停止します。有効中は HTTP8199 と SSDP UDP1900 を使用します。検出にはベンダーの端末 ID ではなくランダムなセッション ID を使います。DLNA に送信者認証はありません。信頼できる LAN で使用し、ポートを外部に転送しないでください。

HTTP(S) の再生 URL は、iPad 上で承認するまで取得しません。確認画面にはホスト名だけを表示し、拒否すると受信も停止します。ユーザー名・パスワードを含む URL、4096文字を超える URL、無効・準備中・非アクティブ時の要求は拒否します。承認後は iPad が選択されたメディアサーバーに直接接続し、通常の接続情報と URL 内のクエリトークンを送ります。HTTP のローカルメディア用に `NSAllowsArbitraryLoads` を維持しています。

SOAP は部分実装です。Play/Pause/Stop/Seek はプレーヤーを操作せず、転送状態と再生位置の応答は固定値です。HTTP 成功は再生成功を示しません。メディアカタログは読み込み時にパス越境と配下のシンボリックリンクを拒否し、既存のパス識別子を保持します。特権プロセスによる同時ファイル置換までは防ぎません。

## 天気

天気機能は任意です。有効にすると Wizard は位置情報の許可を求め、緯度／経度を Open-Meteo の HTTPS 天気予報サービスに送ります。逆ジオコーディングには Apple の位置情報サービスを使って都市名を取得します。端末内のキャッシュには座標、都市、天気、取得時刻を保存します。保存済みの天気を表示でき、位置情報が使えない場合は保存済みの座標で再試行します。天気を無効にすると位置情報更新と定期更新を止めます。配布前に評価対象プロバイダーの現行条件と帰属要件を確認してください。

## 診断と任意連携

実機の診断状態は、一時的な `wizardsystem-debug` マーカーがある場合だけ書き出します。独立した Simulator プレビューではテスト状態を記録できます。状態には壁紙や再生 URL が含まれる場合があるため、共有前に個人情報を除いてください。Cast ログも明示的な有効化が必要で、完全な再生 URL、クエリトークン、要求本文は記録せず、ホストと状態を記録します。天気とパフォーマンス診断には別の有効化マーカーがあります。ソースのエクスポートにログ、ユーザーメディア、端末記録は含めません。

実機の `wizardsystem` URL は、任意の電源アドオンから App を起動する正確な `wizardsystem://main` だけを受け付けます。外部からの設定変更や電源操作は拒否します。Simulator の診断は制限された CLI 経由であり、実機 IPC の権限ではありません。

実験的なファイル連携と任意の WizardPower アドオンには、記載された rootful 環境が必要です。インストーラーはアドオンや特権連携を有効にしません。


任意の電源アドオンは、遠隔 Darwin ロック・起動・状態要求を登録しません。本体の電源ケーブルによる自動化は保持します。診断ログには一時的な `wizardpower-debug` マーカーが必要です。

## 検証の限界

コード確認、ホスト回帰検査、書き出し内容の確認は、3機種でのデータの流れの確認とは別です。リモートサーバーの動作、インストール済み端末の設定、第三者追加物は、それぞれ別途検証が必要です。ネットワーク、保存、利用状況データや診断動作が変わった場合は、この文書を見直してください。
