# 変更履歴

Wizard の主な変更を記載します。ビルドと端末の証拠は[互換性ガイド](COMPATIBILITY.md)で別々に説明します。

## 0.2.0 preview 4 — build 20261112.40（下書き）

- 時計編集画面に「ポスター／標準」の選択肢を追加。既定の「ポスター」は同梱 Anton、「標準」はシステムフォントを使います。「Done」で保存し、「Cancel」で編集前の設定に戻します。
- ソースと Simulator のビルドを確認。実機での受け入れは未実施。
- カレンダーと天気の既存言語 ID は変更なし。
- 時計と日付の編集を切り替えた際に操作パネルを再配置し、画面下端に収める。
- 簡体字中国語、繁体字中国語、英語、日本語の順で紹介ページとガイドを用意。
- 同じ build40 の Simulator キャプチャを更新し、過去の実機画像を別に保持。

## 未リリース

- macOS ホストで動く CI ワークフローとリポジトリ内容の検査を追加。
- 貢献、セキュリティ、互換性のガイドを追加。

## 0.2.0 preview 3 — 20261112.39

- OFL ライセンスの静的 Anton フォントとライセンスをアプリ本体、端末版／Simulator 版のビルド、パッケージに同梱。実際に使われた時計フォント名と同梱ファイルの出所を記録。
- パッケージ作成時に、ディスプレイフォントの欠落・変更・登録漏れを検出して拒否。
- CoreText と同梱の帰属表示付きリソースについて、ビルドメタデータの説明出力を修正。アプリの入力は変更なし。
- Miami 共通グリッドに合わせて GitHub の紹介ページを再構成。デスクトップ／スマートフォン向けレイアウト、中国語／英語版、同一ビルドの実キャプチャ、対応するインストール／開発ガイドを追加。
- 明示的な公開確認までは、リポジトリを非公開、Releases を下書きのまま保留。実機表示は別途受け入れが必要。

## 0.2.0 preview 2 — 20261112.38

- GTA VI Miami のビジュアル方針に合わせてネイティブ表示面と GitHub 表示を再構成。
- 帰属表示付き Vice City の画像を、カタログがない場合の代替表示として追加。既存カタログの識別情報、ユーザー取り込み、保存済みレイアウトは保持。
- 再現可能な画面画像を撮るため、独立したネイティブ Simulator プレビュー用ビルドを追加。
- 確認済みの画像をパッケージに紐付ける検査を更新。実機インストールと実行時受け入れは別途必要。

## 0.2.0-preview.1 — 候補

- 取り込み写真を削除する前に確認を求める。
- 候補ビルド `20261111.37`。実機にはインストールされておらず、実機対応リリースではありません。
